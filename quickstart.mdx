---

This guide walks you through writing a simple C program, compiling it for RISC-V, and running it under Spike using the proxy kernel. You will also take a first look at interactive debug mode.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Spike** — see [Installation](/installation)
- **riscv-gnu-toolchain** — provides `riscv64-unknown-elf-gcc` and related tools
- **riscv-pk** — the RISC-V proxy kernel (`pk`), used to handle syscalls on behalf of bare-metal binaries

<Note>
  The proxy kernel (`pk`) acts as a minimal operating environment. It intercepts system calls from your program (such as `write`) and forwards them to the host OS, so you can run standard C programs without a full OS image.
</Note>

## Step 1: Write a C program

Create a file named `hello.c`:

```c hello.c
#include <stdio.h>

int main() {
    printf("Hello, RISC-V!\n");
    return 0;
}
```

## Step 2: Compile for RISC-V

Use the RISC-V cross-compiler to produce a 64-bit ELF binary:

```bash
riscv64-unknown-elf-gcc -o hello hello.c
```

This produces a `hello` ELF binary targeting the RV64GC ISA by default.

## Step 3: Run under Spike

Simulate the binary using Spike with the proxy kernel:

```bash
spike pk hello
```

Expected output:

```
Hello, RISC-V!
```

Spike loads `hello`, hands system calls to `pk`, and exits when `main` returns.

## Step 4: Explore interactive debug mode

Launch Spike with the `-d` flag to enter interactive debug mode. Execution pauses before the first instruction:

```bash
spike -d pk hello
```

You will see a prompt like:

```
(spike) 
```

From here you can inspect and control execution:

| Command | Description |
|---|---|
| `reg 0 a0` | Print the value of register `a0` on hart 0 |
| `mem 2020` | Print the contents of physical address `0x2020` |
| `r` | Continue execution until the program exits or you interrupt it |
| `q` | Quit the simulator |

Example session:

```
(spike) reg 0 a0
0x0000000000000000
(spike) mem 2020
0x00
(spike) r
Hello, RISC-V!
(spike) q
```

<Tip>
  Press **Enter** at the prompt to step one instruction at a time. Press **Ctrl-C** at any point during normal execution to drop into debug mode without restarting.
</Tip>
