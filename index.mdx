Spike is the official RISC-V ISA reference simulator. It implements a functional model of one or more RISC-V harts, supports the full breadth of standard extensions, and provides interactive debugging, GDB integration, and a C++ extension API for custom hardware modeling.

## What is Spike?

Spike is named after the golden spike used to celebrate the completion of the US transcontinental railway. It serves as the golden reference model for the RISC-V ecosystem — used for architecture validation, toolchain testing, OS bring-up, and hardware design verification.

<Steps>
  <Step title="Install Spike">
    Build from source and install to your RISC-V tools prefix:
    ```bash
    apt-get install device-tree-compiler libboost-regex-dev libboost-system-dev
    mkdir build && cd build
    ../configure --prefix=$RISCV
    make && make install
    ```
  </Step>
  <Step title="Compile a RISC-V program">
    Use the RISC-V GNU toolchain to produce an ELF binary:
    ```bash
    riscv64-unknown-elf-gcc -o hello hello.c
    ```
  </Step>
  <Step title="Run under Spike">
    Execute the binary using the proxy kernel:
    ```bash
    spike pk hello
    ```
  </Step>
  <Step title="Debug interactively">
    Launch Spike in interactive debug mode to inspect state:
    ```bash
    spike -d pk hello
    ```
  </Step>
</Steps>
